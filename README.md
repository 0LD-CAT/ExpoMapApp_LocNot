# Welcome to Expo Map app with Location and Notifications👋

## Инструкция по установке
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/0LD-CAT/ExpoMapApp_LocNot.git
   ```

2. Установите зависимости.
   ```bash
   npm install
   ```

3. Запустите приложение.
   ```bash
   npx expo start
   ```

4. Отсканируйте qr-code в приложении Expo Go.

## Инструкция по тестированию
1. Включить режим разработчика в настройках устройства.
2. Установить и настроить приложение GPS-эмулятор.
3. Разрешить показ уведомлений и отслежевание местоположения.
4. Используя GPS-эмулятор и меняя своё местоположение приближаться и отдаляться от точек на карте, получать уведомления.

## Описание стратегии управления уведомлениями
Создаётся класс для обработки и хранения активных уведомлений, который вызывает запрос на разрешение отправки уведомлений. При попадании в радиус 100 метров к метке (расстояние высчитывается через формулу Хаверсина) создается уведомление, сохраняясь в активных, и отправляется на устройство, пока человек не выходит из зоны метки, повторная отправка уведомлений не происходит, а при выходе из зоны метки уведомление удаляется из журнала.

## Известные ограничения
1. При запрете на получение уведомлений или местоположению, приложение будет работать неккоректно.
